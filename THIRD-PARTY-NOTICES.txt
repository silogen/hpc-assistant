Transitive dependencies

Each container image installs additional transitive Python packages at build
time (for example LangChain Text Splitters, Starlette, Pydantic, NumPy, and
others pulled by the packages above). Those packages retain their original
copyright and license terms as published on the Python Package Index.

The hpc-mcp local-mode virtualenv pins its full third-party graph in
hpc-mcp/requirements.txt; those packages are listed in the hpc-mcp
section above. Run `pip list --format=freeze` in
~/.local/share/hpc-assistant/venv for the installed inventory.

GEAK jobs likewise install transitive Python packages at runtime inside the
compute-node environment (see the GEAK runtime section above). Run
`pip list --format=freeze` inside that environment for a full inventory.

To obtain a complete list of installed packages and versions for a built
image, run inside the container:

    pip list --format=freeze

or rebuild the image and inspect the build log / SBOM.
